    With Claude Code installed and signed in, the AI uses your Claude subscription — no API key. Otherwise put ANTHROPIC_API_KEY=… in ~/.config/spitnpolish/env, pip install anthropic, and restart Spit n Polish. Without either, everything except the AI works.

    Followed when the AI writes sentence and paragraph versions and in the tone pass; the Lab's Voice check marks sentences that break them.

    Plain markdown files in — open them in any editor, back them up or sync them like any other folder. Deleted documents go to its .trash folder.
